#Формат рангов администраторов выглядит следующим образом:
#
#Name = Game Admin
#Include = @ ADMIN BAN SOUND
#Exclude = FUN
#Edit =
#
#Name будет соответствовать чему-либо после '=' и должно быть идентично рангу администратора в admins.txt для привязки, но в остальном не имеет ограничений по форматированию.
#Права ранга определяются ключевыми словами, которые контролируют доступ к группам глаголов и способностей, они чувствительны к регистру и разделяются пробелом без префикса.
#Чтобы не определять права для типа, оставьте его пустым.
#Существует три типа прав:
#Include предоставит ключевое слово рангу.
#Exclude удаляет ключевое слово и имеет приоритет над Include.
#Edit позволит администратору редактировать эти права у других рангов или изменять ранг администратора на другой, если он может редактировать все права, которые тот имеет.
#Edit используется только при включённой загрузке администраторов на основе SQL.
#Если включена загрузка администраторов на основе SQL, ранги и их ключевые слова, перечисленные здесь, будут загружены первыми и переопределят любые с тем же именем, загруженные из базы данных.
#
#Ниже приведены допустимые ключевые слова прав:
#ADMIN = общие инструменты администратора, глаголы и т.д.
#FUN = события, другие действия, ориентированные на события. Доступ к забавным секретам в панели секретов.
#BAN = возможность банить и разбанивать.
#STEALTH = возможность использовать стелс-режим администратора (отображаться под фальшивым именем для всех, кроме других администраторов).
#POSSESS = возможность вселяться в объекты.
#POLL = возможность создавать внутриигровые серверные опросы (требуется БД).
#BUILD = возможность использовать режим строительства.
#SERVER = возможность перезапускать сервер, изменять режим игры или принудительно начинать/заканчивать раунд.
#DEBUG = инструменты отладки, используемые для диагностики и исправления проблем. Полезно давать это кодерам, чтобы они могли исследовать проблемы на живом сервере.
#VAREDIT = каждый может просматривать viewvars/debugvars/как бы вы это ни называли. Это ключевое слово позволяет вам РЕДАКТИРОВАТЬ эти переменные.
#PERMISSIONS = позволяет вам повышать и/или понижать людей в должности.
#SOUND = позволяет вам загружать и воспроизводить ЗВУК.
#SPAWN = трансформации мобов, спавн большинства атомов, включая мобов (высокорисковые атомы, например, чёрные дыры, также потребуют флаг +FUN).
#AUTOADMIN = администратор получает полномочия при подключении. По умолчанию включено, вы можете исключить AUTOADMIN, чтобы роль требовала использования глагола readmin для получения полномочий (это не влияет на способность администратора обходить баны или другие ограничения при подключении, такие как бункер паники или лимит популяции).
#DBRANKS = когда включена загрузка администраторов на основе SQL, позволяет сохранять не временные изменения в панели прав (требуется БД).
#EVERYTHING = Просто даёт вам всё без необходимости вводить каждый флаг.
#@ = специальное ключевое слово для текущего типа прав, которое добавляет все ключевые слова, которые имеет предыдущий ранг того же типа.
